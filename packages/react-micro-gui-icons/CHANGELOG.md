# @nvidia/react-micro-gui-icons Changelog

## [1.0.0] - 2026-09-16

### Added

- Initial public release: React components for all 24 Micro GUI Icons,
  rendered via sprite injection (`<use href="#id">`). Includes tree-shakable
  per-icon subpath imports (`@nvidia/react-micro-gui-icons/icons/<Name>`) and
  a declarative `<NvidiaMicroGuiIconSprite>` component for SSR/static
  rendering.
- Tarball ships `LICENSE` (Apache-2.0 AND CC-BY-4.0), `NOTICE` with
  attribution and trademark terms, and `THIRD_PARTY_NOTICES`.
