# Support

**Support level:** Supported

This project is actively developed and supported. Package APIs follow
[Semantic Versioning](https://semver.org/): icon name removals and export
renames only land in a major release, so a `1.x` upgrade will not break a
working integration. Issue triage and security response are handled
best-effort, the same posture described in
[SECURITY.md](./SECURITY.md#response-sla).

## Getting help

- **Bugs and feature requests:** file a [GitHub Issue](https://github.com/NVIDIA/icons/issues/new/choose).
  Use the bug template for incorrect types, broken exports, build/install
  errors, or accessibility issues in the React components.
- **Icon requests:** open an issue using the icon-request template. Icon design
  is reviewed internally by NVIDIA design/brand owners — see
  [CONTRIBUTING.md](./CONTRIBUTING.md).
- **Questions and usage help:** open a GitHub Issue describing what you are
  trying to do.

## Security issues

Do **not** file public issues for security vulnerabilities. Follow the private
reporting process in [SECURITY.md](./SECURITY.md).

## Scope of support

- Supported: the four published `@nvidia` packages and their documented APIs.
- Not supported through this project: NVIDIA product questions unrelated to
  these packages, or custom icon design work.
